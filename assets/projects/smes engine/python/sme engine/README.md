# DericBI SME Growth Dashboard

A modular, responsive dashboard built with Python Dash to visualize SME performance, overrides, and strategic insights.

## Features
- CSV ingestion and override logic
- KPI cards, charts, and scatter plots
- PDF report generation
- DericBI branding with gold accents
- Responsive layout and tooltips

## Run Locally
1. Install dependencies: `pip install -r requirements.txt`
2. Place your CSV in `data/sme_data.csv`
3. Add your logo to `assets/dericbi_logo.png`
4. Run: `python app.py`
